## Hi!

I'm a computer science student at Universidade de São Paulo (USP), ICMC. I'm
interested in game development, computer graphics, image processing, low-level
development and unix systems. My repositories are mostly for personnal
projects.

## Favorite projects

- [**SoftBlocks**](https://github.com/GabrielMtins/SoftBlocks): A software
  renderer for a generated voxel world optimized with OpenMP.
- [**SaveState**](https://github.com/GabrielMtins/SaveState): A TUI program
  that lets you catalog games you have played and add diary entries for them.
  It uses sqlite3 to manage its database.
- [**r_json**](https://github.com/GabrielMtins/r_json): A plain C89 library
  (with no dependencies from standard library) that parses JSON files. It
  manages its own memory through memory arenas.
- [**Nestylize**](https://github.com/GabrielMtins/nestylize): A software that
  converts a real image to a pixel art style through image processing
  algorithms such as color quantization and dithering.
- [**A Escape Night from the
  Desert**](https://github.com/GabrielMtins/A-Escape-Night-from-the-Desert): A
  FPS game written in C99 with mod support through Lua and an optimized
  software renderer.
